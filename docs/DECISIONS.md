| 21 | `чек` – платная отработка, **в игру не переносим** | §3, §13.2 |

## 2. Мои предложения (🟡)

| № | Решение | Где в GDD |
| :-- | :--- | :--- |
| 1 | Поражение объявляется в момент сдачи списанной работы, окно сдачи 2,5 с | §16 |
| 2 | Любая доля копии в сдаче = списание (без порога) | §3, §8.2 |
| 3 | Доверие класса 0–100: цена ложных санкций, на победу не влияет | §12 |
| 4 | Classroom даёт полное решение только для «слитых» или дублирующихся вариантов | §9.3 |
| 5 | Слоты телефонов: известные / скрытые / муляжи; скрытые ищутся обыском | §15 |
| 6 | CCTV показывает **только экраны**, не людей и не руки | §10.1 |
| 7 | В CCTV – мини-карта класса, потому что сетка 3×5 больше не зеркалит рассадку | §10.2 |
| 8 | Жалюзи на правой стене – опциональная механика | §4.7 |
| 9 | Godot 4.3 + GDScript | §21 |
| 10 | 5 уровней; MVP – 1 уровень | §17, §25 |

## 3. Открытые вопросы (❓)

| № | Вопрос | Варианты | Моя рекомендация |
| :-- | :--- | :--- | :--- |
| 1 | Поражение сразу или к звонку? | Сразу / к звонку | **Сразу** + разбор |
| 2 | Любая доля копии = списание? | Да / порог 10–30% | **Да** |
| 3 | Нужен ли показатель доверия? | Да / нет | **Да** |
| 4 | Classroom даёт полное решение всегда? | Всегда / только для слитых | **Только для слитых** |
| 5 | Знает ли преподаватель точное число телефонов? | Да / нет | **Известные – да, скрытые – нет** |
| 6 | Выгонять учеников? | Да / нет | **Нет в MVP** |
| 7 | Жалюзи? | Да / нет | **Нет в MVP** |
| 8 | Godot или Unity? | Godot / Unity | **Godot 4.3** |
| 9 | Имя преподавателя: реальное или вымышленное? | Реальное / вымышленное | **Вымышленное** |
| 10 | Балансный лимит доп. вариантов в MVP | 1 / 2 / 10 | **2**, хотя технический предел +10 |
| 11 | Сколько уровней в MVP | 1 / 2 | **1** |
