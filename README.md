# Spot the Cheater

> **3D-симулятор преподавателя от первого лица:** 15 студентов, лабораторная по программированию и одна пара, чтобы никто не списал.

**Статус:** проектирование. GDD v0.7. 3D-сцена класса ещё не собрана, старый 2D-каркас удалён.

---

## Что это

Игрок — преподаватель в компьютерном классе. Перед ним 15 учеников, каждый пишет лабораторную в редакторе кода. Кто-то работает честно, большинство ищет способ списать: GPT в браузере, быстрый ответ Google, готовая лаба в Google Classroom, телефон под партой.

Задача — заметить нарушение, собрать доказательство и вмешаться до сдачи. Победа: **никто не списал**. Поражение: **хотя бы один сдал списанную работу**.

### Коротко

| Параметр | Значение |
| :--- | :--- |
| Камера | От первого лица |
| Игрок | 1 преподаватель |
| NPC | 15 учеников |
| Пара | 10 минут |
| Способы списывания | GPT, Google, Classroom, телефон |
| CCTV | Сетка 3×5, клик — на весь экран |
| Журнал | Excel: варианты, статусы, доп. варианты |
| Телефоны | Коробка на столе, подсчёт, скрытые устройства |
| Класс | 10 × 12 м, U-образная расстановка + остров |

## Стек

- **Godot 4.3**, GDScript — предложение, финально не подтверждено (см. `docs/DECISIONS.md`).
- 3D low-poly, запечённые световые карты.
- 15 экранов учеников — `SubViewport` с 2D-UI, а не 15 3D-камер.
- Git + Git LFS для ассетов.

---

## Быстрый старт

1. Установить **Godot 4.3**.
2. Открыть `project.godot`.
3. Главная сцена пока не назначена: 3D-класс будет добавлен на этапе блокинга.
4. Дизайн — в `docs/GDD_3D.md`, решения — в `docs/DECISIONS.md`.
